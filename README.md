# OAuth 2.0 / OpenID Connect Node.js Demo

A TypeScript/Node.js demonstration of modern authentication
and authorization flows.

## Demonstrates

- OAuth 2.0 Authorization Code flow
- PKCE
- OpenID Connect
- ID tokens
- Access tokens
- Refresh tokens
- State validation
- Nonce validation
- JWT claims
- Protected API endpoints
- Authentication middleware

## Technology

- TypeScript
- Node.js
- Express.js
- OAuth 2.0
- OpenID Connect
- JWT

## Security Focus

- Authorization code protection
- PKCE
- State validation
- Nonce validation
- Token expiration
- Issuer validation
- Audience validation
- Secure token handling

> This is a learning/demo project and contains no real
> credentials or production identity-provider configuration.
